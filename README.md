# BPSR-AutoFishing

Automates fishing in Blue Protocol: Star Resonance using pixel detection and mouse and keyboard input.

## What it does

- Detects fishing states and performs the required actions.
- Can switch fishing rods automatically. Keep the rods and bait you need in your inventory.

## Quick start

1. Download and run **BPSR-AutoFishing.exe** from the [latest release](https://github.com/Joseleelsuper/BPSR-AutoFishing/releases/latest).
2. Open the game and move to a fishing spot.
3. Press **F9** to start or pause automation. Press **F10** to exit the script.

## Hotkeys

- **F9**: start or pause automation.
- **F10**: exit the script.

## Requirements and compatibility

- Windows.
- To run the source file, install [AutoHotkey v2.0.19](https://github.com/AutoHotkey/AutoHotkey/releases/tag/v2.0.19).
- Use a 16:9 game window. The 16:10 resolution 1440x900 is not supported; a centered 1280x720 window is recommended.
- When using Steam or the official launcher, run the game as administrator.
